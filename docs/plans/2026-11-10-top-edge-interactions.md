# 屏顶交互与设置改进

用户已要求运行本机 Niya，评估并加入双指切页、自动刘海/顶栏适配、登录自启和关于页。本轮实现这些具体功能，保持现有六功能与数据存储。

## 方案

- 使用 AppKit 窗口范围内的触控板滚动事件识别横向切页；纵向滚动、输入、弹窗与拖放不受影响。每次手势最多一页，跳过关闭的功能，到边缘停止。
- 屏顶入口沿用现有开启状态。模式默认自动：有可用内置实体刘海则使用刘海，其他情况选择主屏顶栏。可手动选择刘海或顶栏。屏幕变化后重新检测，不覆盖用户偏好。
- 顶栏以菜单栏下缘的一条小型材质条标识入口，悬停一秒或点击展开现有卡片，离开300毫秒收起。顶栏也支持既有文件暂存拖入流程；睡眠与会话失活时隐藏。
- 通用设置加入基于 SMAppService 的登录自启，状态来源于系统，默认不代替用户开启。
- 新增关于页：应用版本、构建号、Copyright © 2026 Ronny Cao、GitHub 项目链接与 Star 支持文案；中英文完整。

## 实施与验收

1. 先验证 Niya 本机可见设置与界面，区分实际观察与尚未实测的手势。
2. 几何选择、设置持久化、手势分类和登录项状态流分别做回归测试。
3. 合并设置与窗口接线，运行完整SwiftPM测试、逻辑测试及Release构建。
4. 在本机检查自动/顶栏模式、关于页和开关状态。真实触控板、无刘海实体Mac及登录后启动若未能现场验证，交付时明确说明。
