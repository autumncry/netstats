# NetStats v2.01

GitHub tag **`v2.01`** · App **`2.0.1` (build 28)** · **macOS 14+**

通用安装包支持 Apple Silicon (`arm64`) 和 Intel (`x86_64`)。

## 下载与安装

1. 下载 **[NetStats-2.0.1.dmg](https://github.com/autumncry/netstats/releases/download/v2.01/NetStats-2.0.1.dmg)**。
2. 先退出正在运行的旧版 NetStats，再打开 DMG，把 `NetStats.app` 拖入 Applications（应用程序），替换旧版。
3. 从应用程序打开 NetStats。原有设置、剪切板历史和暂存架数据会继续保留。

[SHA-256 校验文件](https://github.com/autumncry/netstats/releases/download/v2.01/NetStats-2.0.1.dmg.sha256)

本次应用使用临时签名（ad-hoc），没有 Developer ID 签名或 Apple 公证。首次打开若被 macOS 拦截，请在确认下载来源后，到“系统设置 → 隐私与安全性”允许打开。

## 更新内容

- **剪切板**：修复图片缩略图覆盖“图片”标题和时间的问题。宽图、长图和方图均在固定区域内按比例显示，完整预览保持可用；统一图片和文字条目的行高。
- **刘海悬停**：修复独立设置窗口保持打开时，悬停卡片无法再次弹出的问题。
- **独立设置窗口**：所有详细配置集中到独立窗口，菜单栏、刘海卡片和完整监控共用同一设置入口；切换其他应用时设置窗口保持打开。
- **网络卡片**：下载、上传改为对齐的两行，配套双色趋势图；移除卡片上的接口缩写，详细接口信息仍在完整监控中。
- **功能栏**：统一图标区域和文字基线，修正暂存架与其他功能的对齐。
- **Apple 天气**：简化为四行文本输出，保留旧 JSON 兼容；改进快捷指令缺失、无输出和温度格式错误的提示。新增带截图的入门指南，使用北京市作为配置示例；用户仍可自行选择其他城市。

天气功能需先在系统快捷指令中建立 `NetStats Weather`，再到 NetStats 设置中测试连接。**安装包不会自动创建快捷指令。** 见 [新版天气配置指南](https://github.com/autumncry/netstats/blob/v2.01/docs/weather-shortcut.md)。

## English

This maintenance release fixes clipboard thumbnails overlapping their labels, restores notch hover while Settings is open, moves preferences into a standalone window, aligns network download/upload rows and feature icons, and improves Apple Weather shortcut setup and error messages. Existing preferences and local history are preserved.

Quit the old app, download the universal DMG, drag NetStats into Applications and replace the old copy. The app is ad-hoc signed, without Developer ID signing or Apple notarization. Weather still requires a user-created shortcut; see the guide above.

This release does not publish the npm package or update the separate Homebrew tap. Use the attached DMG.
