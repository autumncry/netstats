# NetStats v2.00

Git tag: `v2.00`. App and npm semantic version: `2.0.0`, app build27.

## Changes / 更新

- A compact360pt native glass card shared by the menu-bar and physical-notch entrances, adapting to system appearance and accessibility settings.
- Click-to-switch Dock for Network, Device, Calendar, Weather, Clipboard and Shelf, with shared per-feature settings. Network, Device and Shelf are initially enabled.
- Network throughput, short history and session totals; CPU, GPU model/optional load, memory and startup-volume capacity. Disk I/O remains clearly labeled as aggregate across devices.
- Read-only calendar browsing after explicit system authorization, plus a user-configured Apple Weather Shortcuts bridge with caching, manual refresh and process timeout.
- Local text/image clipboard history, search/paging, preview, copy, pause, excluded apps and independent count limits. Defaults:30days and unlimited counts. Pause/disable/Clear cancel pending captures.
- Persistent file-reference shelf with drag in/out, open, remove and relink; removing references never deletes originals.
- 1-second hover,300ms exit grace,500ms valid-file drag dwell, editing/popover holds and child-first Escape handling. Existing Native/Terminal detailed monitoring and Clash remain available.

## Setup / 首次配置

Calendar requires an explicit Full Access grant; NetStats only queries events. Newer macOS versions must allow background clipboard access before automatic collection. Weather requires a dedicated system shortcut and a successful connection test: see [setup instructions](../weather-shortcut.md).

No new Accessibility, Input Monitoring or Screen Recording grant is required by the card. See [privacy](../PRIVACY.md) and [permissions](../PERMISSIONS.md).

## Validation / 验证

67 automated tests, existing logic checks, and Release builds passed during development. Tests cover persistence, privacy controls, retention, hover geometry/timing and actual test-child process timeout/cancellation. Offscreen renders do not establish live desktop glass or hardware behavior.

Calendar/clipboard grants, the real weather shortcut, physical-notch dragging, foreground input, full-screen/external-display changes and sleep/wake remain hands-on acceptance items. Development bundles use a local ad-hoc signature; distribution signing and notarization have not been established.

This source version does not publish the npm package or update the separate Homebrew tap automatically.
